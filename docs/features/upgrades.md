# Upgrades

Upgrades are installed in the Portable Beehive's **upgrade grid** — a spatial grid where each upgrade has a unique shape that must fit without overlapping. Rotate upgrades to find the best layout.

## Available Upgrades

### Rapid Wings
Increases bee flight speed.
- **+25%** speed per upgrade

### Swarm Intelligence
Increases the maximum number of concurrent bees.
- **+8** bees per upgrade

### Honey Efficiency
Reduces fuel consumption and improves bee performance.
- **-15%** fuel consumption per upgrade
- **-25%** break time per upgrade
- **+2** carry capacity per upgrade

### Honey Tank
Increases the portable beehive's honey fuel capacity.
- **+200** fuel capacity per upgrade

### Drone View
Enables the drone camera for remote surveying. See [Drone View](#drone-view) below.

### Inventory Access
Allows bees to search inside shulker boxes in connected inventories when looking for materials.

## Drone View

With the Drone View upgrade installed:

1. Press the **drone keybind** to launch a drone from your beehive
2. Use **WASD** to fly the drone camera around
3. Issue construction/deconstruction commands remotely
4. Press the keybind again to return

The drone's range is limited by the `droneBaseRange` config (default 32 blocks), extended by Drone Range upgrades.
