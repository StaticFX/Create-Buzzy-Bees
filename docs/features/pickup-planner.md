# Pickup Planner

The Pickup Planner dispatches bumble bees to collect loose items from the ground.

## Usage

1. Hold the **Pickup Planner**
2. **Right-click** to set the first corner
3. **Right-click** again to set the second corner
4. Press the **start keybind** (default: R) to begin pickup

The selection and control scheme is identical to the [Deconstruction Planner](/features/deconstruction-planner) — Ctrl for free-aim, Ctrl+Scroll to resize, Shift+RMB to cancel.

## Requirements

- **Bumble bees** must be stored in the hive (regular bees won't handle pickup jobs)
- A **drop-off logistics port** must be in the network for bees to deliver items to

## Stuck Reasons

If the job stalls:

- **No bumble bees available** — you need Mechanical Bumble Bee items in your hive
- **No logistics port to deliver items** — add a logistics port in drop-off mode
