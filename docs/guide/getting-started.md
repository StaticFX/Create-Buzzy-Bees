# Getting Started

## Requirements

- Minecraft **1.21.1**
- **NeoForge** (or Forge 1.20.1 for the legacy version)
- [Create](https://modrinth.com/mod/create) v6.0.9+
- [Curios API](https://modrinth.com/mod/curios) (for wearing the Portable Beehive)

## Installation

1. Install NeoForge for Minecraft 1.21.1
2. Drop **Create Buzzy Beez** and its dependencies into your `mods/` folder
3. Launch the game

## Your First Build

### 1. Craft the basics

You need three things to get started:

- **Mechanical Beehive** — the block-based hive that houses your bees, powered by rotational force
- **Mechanical Bee** — the worker bee item (place in the hive)
- **Construction Planner** — the tool for selecting and deploying schematics

### 2. Set up a beehive

1. Place the **Mechanical Beehive** and connect it to a rotational source (shaft, cogwheel, etc.)
2. Right-click to open it and place **Mechanical Bee** items inside
3. The hive's range and bee count scale with RPM

### 3. Place logistics ports

Bees need **Logistics Ports** to gather building materials:

- Set a port to **Provider** mode and connect it to a chest/vault containing your blocks
- The port's filter determines which items bees can pick up from it

### 4. Build a schematic

1. Hold the **Construction Planner** — the inline HUD appears
2. Use **Alt+Scroll** to browse your schematics
3. **Right-click** to deploy, then position with Create's schematic overlay
4. Select the **Construct** tool and right-click to start building

Your bees will fly out, gather materials from the logistics ports, and place them block by block.
